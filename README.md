# ポケットインターバル

スマホをポケットやアームバンドに入れたまま、**振動のパターンだけで「走る／歩く／終了」がわかる**インターバルタイマーです。
HTML / CSS / JavaScript だけの静的サイトで、バックエンド・ログイン・広告はありません。

## 振動パターン

| 合図 | 振動 | ビープ音 | 音声 |
|---|---|---|---|
| 走る | 長く1回（700ms） | 高めの長音1回 | 「N本目。走って」／最後は「ラスト。走って」 |
| 歩く・ウォームアップ | 短く2回（180-120-180ms） | 低めの短音2回 | 「歩いて」 |
| 切り替え3秒前 | 毎秒ちょん（70ms ×3） | 短いピッ ×3 | なし |
| 終了 | 長く3回（700ms ×3） | 長音3回 | 「終了です。おつかれさまでした」 |

パターンの長さは `app.js` の `VIBE` / `BEEP` で変えられます。

## ファイル

```
index.html            画面（設定・実行・終了）
style.css             見た目
app.js                タイマー・振動・音・Wake Lock・設定保存
sw.js                 オフラインでも開けるようにする Service Worker
manifest.webmanifest  ホーム画面に追加したときの設定
icon.svg, icons/      アイコン
```

## 公開のしかた

**https で公開してください。** 画面のスリープ防止（Wake Lock）は https でないと動きません。

- **GitHub Pages**：このフォルダの中身をリポジトリに置き、Settings → Pages で公開
- **Netlify Drop**：https://app.netlify.com/drop にフォルダをドラッグ＆ドロップ

公開後、Android の Chrome で開き、メニューの「ホーム画面に追加」をしておくと、アドレスバーなしの全画面で使えて、電波がない場所でも開けます。

## 使うときの注意

- スタート後の5秒は準備時間です。その間にポケットへ。
- **画面はつけたまま**にしてください。電源ボタンで画面を消すと、Android の仕様で振動が届かなくなります（タイマーの時間自体はずれません）。
- 「誤タッチ防止」がオンのとき、一時停止と終了は長押し（0.7秒）です。ポケット内の誤操作や、戻るジェスチャーでの誤終了も防ぎます。
- 振動しないときは、端末のバイブレーション設定・バッテリーセーバー・おやすみモードを確認してください。

## 実機での確認項目（完了条件）

1. 設定画面の「振動パターン」を順にタップし、走る／歩く／終了／3秒前が手で区別できる
2. スマホをポケットに入れて数本走り、画面を見ずに切り替えがわかる
3. 20分のメニューを最後まで流し、画面が消えないこと、終了画面の時間が 20:00 になっていること
